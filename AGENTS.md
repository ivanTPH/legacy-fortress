# Legacy Fortress Agent Rules

Preserve the existing project and security instructions supplied to development agents. For customer-facing UI work, the permanent visual authority is [`design/brand-guardian/DESIGN_AUTHORITY.md`](design/brand-guardian/DESIGN_AUTHORITY.md) and the implementation guide is [`design/brand-guardian/BRAND_APPLICATION_GUIDE.md`](design/brand-guardian/BRAND_APPLICATION_GUIDE.md).

## Brand Guardian

Every customer UI change must identify its approved source screen/state, use the canonical tokens and shared components, preserve canonical data and security behaviour, avoid obsolete patterns, verify desktop/mobile impact, run `npm run design:check` plus relevant tests, and report rendered evidence or the exact browser blocker. Enterprise and System Administration use their separate approved journey designs and shells.
