# Material Symbols Rounded source

The locally bundled `public/fonts/material-symbols-rounded.woff2` is the unmodified Rounded variable font from Google's official [`material-design-icons` repository](https://github.com/google/material-design-icons/tree/49d4db35df873165d6bd6ba09b063c7dafbac2f4/variablefont). The upstream source path is `variablefont/MaterialSymbolsRounded[FILL,GRAD,opsz,wght].woff2` at commit `49d4db35df873165d6bd6ba09b063c7dafbac2f4`.

SHA-256: `1f8b34a4a7c54eb110b4e51f5233b3d459cbbec2f7ef4e3e1047751918ec5a66`.

Google [documents the Apache 2.0 license](https://developers.google.com/fonts/docs/material_symbols) for Material Symbols. A copy of the upstream license is included as `public/fonts/material-symbols-LICENSE.txt`. The font is served locally; the application does not fetch icon glyphs from Google at runtime.

The default icon axes are `FILL 0`, `wght 400`, `GRAD 0`, with optical size matched to the rendered size from 20 to 48. Selected icons can request `FILL 1`. The Version 3 nine-dot `apps` logo tile is available as `BrandGlyph`; existing branding remains in place until the scope of Q19 is decided.
