# Version 3 implementation deviations

## Phase 3 customer shell

- `/add` and `/actions` are functional route destinations to existing secure areas, with complete designed screens deferred to Phase 4 as the owner approved.
- The mobile shell retains a 44px navigation-menu control so users can reach the six Vault areas before the Phase 4 mobile Home list is built.
- The bell links to existing notification settings. Event notifications and the designed event Sheet await the Q13 data contract; no event count or fake notifications are shown.
- Action Centre counts are omitted from shell navigation until the canonical, linked-safe count rule is approved in Q4.
- The UAT safety banner retains its existing copy and wraps on a narrow phone; it is an environment control rather than customer chrome.
- The Dashboard and other existing page bodies keep their current layouts until Phase 4. Their Phase 3 screenshots prove the shell around actual app content, not completion of the screen redesign.
